## 解释范围

需要同时比较分阶段双历史与相同历史跨度的通用历史，以及加/不加距离折扣。若主要收益也出现在通用历史版本，应把证据归于执行顺序或周期历史，不能声称已经证明分阶段 loop 信息的独立贡献。

驻留候选召回统一使用 Score EMA 在 source 时刻的同一驻留集合。OLED 仅适配 gate 驻留与动态层配额，没有实现 CPU 补偿。统计表每级的容量上限相同，但实际 cell 数不同。首轮统计包含每个请求的冷启动；预测召回只统计存在实际后继的 source。

最终结论还需要未查看的新请求、独立验证集及真实受限显存的端到端执行器。当前结果不支持将命中率直接换算成加速。
